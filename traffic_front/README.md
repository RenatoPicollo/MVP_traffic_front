# Front End

Este projeto faz parte do MVP desenvolvido para a disciplina **Desenvolvimento Full Stack Básico**

---
## Como executar

1 - Descompacte o arquivo "exemplos_placas.zip" para alguma pasta de escolha do usuário.

2 - Acesse o arquivo "index.html" no caminho "MVP/traffic_front", após download dos repositórios e demais instruções presentes no arquivo README.md, contido na pasta "traffic_api".

3 - No arquivo HTML, selecione um local pré definido.

4 - Selecione "Escolher Arquivo" e carregue um dos arquivos de imagem.

5 - Clique em "Analisar e Registrar".
